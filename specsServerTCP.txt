VERSION 1.3
    Server Start und Abfrage der Client Queue --> Initiale Funktion des Moduls
        ├── TCP listening Socket starten
        ├── TCP Clientanfragen aus Queue annehmen
        ├── Jeden Client in der Sessions Dictionary aufnehmen und loginStatus=False setzen
        ├── Für jeden Client einen eigenen Thread starten
        ▼
    Client Handler --> Paralleles handling der Verbundenen Clients/Sockets
        ├── Client in der Client Liste für TCP Verbindungen aufnehmen
        ├── TCP payload aus dem TCP stack für den jeweiligen Client abholen
        ├── TCP payload puffern, parsen und verwalten
        ├── Weiterführenden Handler aufrufen
        ├── Client aus Sessions Dictionary und der Client Liste nach Verbindungsabbruch entfernen
        ▼
    Login Handler --> Wird aufgerufen, wenn der Client MESSAGE_TYPE=='LOGIN' sendet
        ├── Passwort gegen die Server-DB prüfen
        ├── Wenn PW korrekt, loginStatus=True setzen, Token erstellen und Token an Client senden
        ├── Sessions Dictionary für den Socket um die Values für userName und clientToken erweitern
        ├── Bei falschem PW eine Fehlermeldung an den Client senden
        ▼
    Message Handler --> Wird aufgerufen, wenn der Client MESSAGE_TYPE=='MSG' sendet
        ├── Holt den userName zum jeweiligen Socket aus der Sessions Dictionary
        ├── Prüft, ob loginStatus=True ist
        ├── Wenn loginStatus==True, Broadcaster aufrufen
        ├── Wenn loginStatus=False, Fehlermeldung printen
        ▼
    Broadcaster
        ├── Sendet die eingehenen Nachrichten an alle Clients in der Client Liste
        └── Der ursprüngliche Sender der Nachricht wird beim Broadcasten nicht berücksichtigt
